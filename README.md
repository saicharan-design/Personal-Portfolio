# Personal Portfolio Website

🌐 **Live Website:** https://saicharan-design.github.io/Personal-Portfolio/

## About the Project

This is a responsive personal portfolio website created using HTML and CSS. It showcases my introduction, educational background, technical skills, projects, and contact information as a first-year Computer Science Engineering student.

## Features

- **Navigation Bar:** Easy navigation between different sections.
- **Hero Section:** Personal introduction with a profile image.
- **About Me:** Brief introduction and educational background.
- **Skills:** Displays technical skills and interests.
- **Projects:** Showcases three projects with descriptions and technologies used.
- **Contact:** Provides email and GitHub profile links.
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Modern UI:** Blue and purple colour scheme with hover effects.

## Projects Included

### 1. Rule-Based Chatbot
A Python chatbot that identifies keywords and responds using predefined replies.

**Technologies:** Python, NLTK

### 2. Web Scraper
A Python program that extracts book titles and prices from webpages.

**Technologies:** Python, Requests, BeautifulSoup

### 3. Student Record Manager
A menu-driven program that manages student records and calculates average marks.

**Technologies:** Python, Data Structures
